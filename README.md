# 悦居生活服务平台
## 项目简介
本项目是基于 **Spring Cloud Alibaba** 搭建的家政O2O微服务学习项目，无线上真实用户、未部署生产环境，核心用于练习微服务架构、分布式高并发场景解决方案，复现家政平台完整业务链路，针对性解决秒杀超卖、缓存同步、分表查询、订单幂等等线上常见问题。

## 技术栈
### 核心框架
- 微服务：Spring Cloud Alibaba
- ORM：MyBatis-Plus、Sharding-JDBC
- 数据库：MySQL 8.0

### 中间件
- 缓存：Redis + Redisson（分布式锁、Lua原子脚本）
- 消息队列：RabbitMQ（延时消息、异步数据同步）
- 检索引擎：Elasticsearch + IK中文分词器
- 数据同步：Canal（监听MySQL binlog日志）
- 定时任务：XXL-JOB

### 开发工具
Maven、Lombok、Postman、Git

## 核心功能与技术亮点
### 1. ES全文检索 + Canal实时数据同步
- 使用Elasticsearch+IK分词实现家政服务多条件模糊检索，接口响应控制在200ms内；
- 通过Canal监听MySQL binlog变更，结合RabbitMQ异步推送数据至ES，实现MySQL与ES秒级数据同步，数据一致性达98%；
- 解决数据库模糊查询慢、分页性能差的痛点。

### 2. 优惠券秒杀高并发防超卖方案
- XXL-JOB定时预热优惠券库存至Redis，缓解数据库瞬时并发压力；
- Redis + Lua脚本实现库存原子扣减，彻底避免并发超卖问题；
- 抢券成功后写入Redis队列，多线程异步落库，队列粒度加锁防止重复写入数据库，保障万级并发场景下数据准确。

### 3. 订单全链路高可靠优化
- 基于Redisson分布式锁实现下单幂等，重复下单创建率为0；
- 使用策略模式重构7种订单状态取消逻辑，降低代码耦合、便于拓展；
- RabbitMQ延迟消息处理超时未支付订单，自动关单并释放优惠券库存，处理时效从分钟级优化至秒级。

### 4. MySQL分表 + 冷热数据分离存储
- Sharding-JDBC按照用户ID哈希水平分表，分散单表数据压力；
- XXL-JOB定时任务将超过15天的已完成冷订单归档至历史订单表；
- 热订单单表数据控制在百万级以内，订单查询性能提升3倍。

## 环境前置准备
启动项目前需本地部署并启动以下服务：
1. MySQL 8.0
2. Redis
3. RabbitMQ
4. Elasticsearch
5. Nacos
6. Canal服务端 & 客户端
7. XXL-JOB调度中心

## 项目启动步骤
1. 执行项目根目录下SQL脚本，初始化数据库、基础测试数据；
2. 修改各微服务模块 `application.yml` 配置文件，替换本地中间件IP、账号密码；
3. 启动Nacos注册配置中心；
4. 依次启动网关、各业务微服务模块；
5. 启动Canal客户端监听MySQL数据变更；
6. 通过Postman测试完整业务流程：用户注册→浏览家政服务→领取优惠券→下单→超时自动关单。

## 项目说明
本项目为个人后端学习实践项目，无线上生产流量、无真实C端用户，所有功能按照企业级后端开发规范实现，完整落地分布式锁、缓存一致性、异步消息、分库分表、全文检索等面试高频高并发解决方案，代码开源仅供学习参考。
